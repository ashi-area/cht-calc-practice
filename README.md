# 計算練習

中華電信招考（企業客戶技術服務）用的計算練習 App：四則運算和計算機概論的計算題。

- 純靜態網頁，沒有後端、沒有登入、沒有追蹤程式
- 可以加到 iPhone 主畫面，第一次打開後沒有網路也能練習
- 進度只存在自己的裝置裡，可以匯出／匯入 JSON 備份

## 目前的內容

- 四則運算 Lv1–3：一位數加減、兩位數加減（進位、借位）、九九乘法和兩位數 × 一位數
- 進位轉換 Lv1–3：二進位、十進位、十六進位互換，依位數分級

答錯時會一步一步列出算法；常錯的題型之後會比較常出現。

## 檔案

- `js/arith.js`、`js/base.js`：出題和解題
- `js/engine.js`：等級升降、弱點加權、備份格式
- `js/app.js`：畫面
- `sw.js`：離線快取。發布新版時把裡面的 `VERSION` 加 1
- `tests/`：單元測試，用瀏覽器打開 `tests/index.html` 就會執行，標題顯示 PASS 代表全部通過
